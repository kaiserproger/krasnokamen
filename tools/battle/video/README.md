# Battle telemetry overlay and composition

Python 3 standard library, ffmpeg with libx264, drawtext, xfade and AAC, and DejaVu Sans Bold at `/usr/share/fonts/truetype/dejavu/DejaVuSans-Bold.ttf` are required. No wall-clock is read. Inputs are the E1 `/telemetry.jsonl` export and C3 `shot.frames.jsonl`. One PNG per C3 frame, at 60 fps; exact tick join uses `last_applied_tick` (the last shutter sample when motion blur is enabled). Missing tick fails instead of inventing telemetry. Output directory must not exist.

```sh
python3 tools/battle/video/overlay.py --telemetry /work/telemetry.jsonl --frames /work/edit.frames.jsonl --out /work/overlay
python3 tools/battle/video/compose.py --shot-a /work/shot-a.mp4 --shot-b /work/shot-b.mp4 --overlay '/work/overlay/overlay-%06d.png' --music /work/music.wav --title-file /work/title.txt --shot-a-seconds 6 --crossfade 1 --duration 10 --resolution 1080p --output /work/final.mp4
```

Use `--resolution 4k` for 3840x2160. Both recipes encode H.264 High with 2 B frames, closed 30-frame GOP, CRF 16, AAC 384k/48 kHz, BT.709 limited-range tags and faststart. Music is looped and loudness-normalized; use only licensed audio. Title file is literal UTF-8, shown during the first three seconds. Shot A must cover its stated duration; shot B must cover `duration - (shot-a-seconds - crossfade)`. Overlay sequence must cover the whole edit; ffmpeg ends when it ends. There is no implicit time resampling or telemetry estimation for edits: provide `/work/edit.frames.jsonl` in output-frame order with `frame` renumbered from zero. During a crossfade there are two visible times; choose one source tick per output frame explicitly, retain the edit mapping, and do not imply the panel describes both. For a continuous time-accurate telemetry section, avoid crossfading footage from distinct ticks while the panel is visible. Synchronize audio to the edit before using this recipe if required.

Graph: 180 tick history; green = full active `wall_us` MSPT on a fixed 0–100 ms scale, clipped at 100; amber 50 ms budget line; blue = instantaneous TPS on a 0–20 TPS scale, clipped at 20 (numeric TPS remains unclipped). Missing ticks create line gaps. Numeric cgroup CPU is percent of one CPU (may exceed 100), derived from consecutive host-sample `usage_usec` and sampled timestamp; steal from proc-stat deltas, memory is cgroup bytes in GiB. Host values are held from the last sampled tick; unavailable counters are `N/A`, not zero. `battle.units` is the number of faction rows, not the number alive; `battle.alive` supplies per-faction living counts. Faction IDs are read from the map, ordered numerically; absent battle data displays `N/A`, and more than two factions is rejected. Metrics are not synthesized from footage.

Run focused tests: `python3 tools/battle/video/test_overlay.py`. A failed or interrupted render can leave partial output; use a new output path for each attempt. The sample synthetic render in the receipt is not a battle or proof of live server performance.
