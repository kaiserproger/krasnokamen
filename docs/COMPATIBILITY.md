# Vanilla compatibility — Minecraft Java 26.3

**Source snapshot: 2026-11-07, base `ffd52010`; draft, not a drop-in vanilla replacement.**
The native `krasnokamen` server uses canonical Java 26.3 (777) and serves the
release window 26.1.2–26.3 (775/776/777) through adjacent translation steps.
Import installs every endpoint cache automatically; bumps keep older versions.
Static source and tracked regressions are not proof of a current real-client pass. See the
[real-client gate contract](development/real-client-gates.md),
[DoD](DEFINITION_OF_DONE.md), and [historical ledger](VALIDATION_LEDGER.md).

`partial` denotes implemented behavior with an indicated limitation or evidence
gap; `works` is limited to the stated scope, not complete parity. `missing`
means absent, and `n/a` is not a vanilla-server parity requirement. A linked test
is proof only of its asserted scope; no test was executed for this snapshot.
