# Solaris 1.0 "Pauline" RC4

**Draft — not release-ready.** Final packaged builds, release gates and matching
client/Loader/plugin revisions have not yet been verified. Do not publish these
notes unchanged.

RC4 targets Minecraft Java Edition 26.3, with 26.1.2 protocol support as in
[RC3](https://github.com/kaiserproger/solaris/releases/tag/v1.0.0-rc.3).

## Changes under validation

- Fixes for crafting inventory transfers, wall placement, sheep and goat
  presentation, and several other owner playtest findings.
- Settlement map and storage interface improvements, along with automatic
  crafting of dependency chains.
- Client rendering corrections for camera poles, directional block shading,
  sulfur cubes, cushions, poplar boats, giants, bee anger and decorated-pot patterns.
  These need the matching client build; model variants and full vanilla visual
  parity are not yet established.
- Screenshots from the opaque client surface no longer contain unintended
  transparent pixels from the framebuffer.
- Container block-entity privacy fixes for the container types exercised so far.
  Decorated pots intentionally withhold contents and unopened loot from clients,
  unlike vanilla; comprehensive coverage of all block entities is not established.
- Armadillo scute shedding now advances its countdown in game ticks rather
  than once per ten-tick threat check.
- Grounded entities with levitation are no longer incorrectly classified as
  resting on the tick when the effect is applied.
- Closing an inventory with an item on the cursor now clears the client cursor
  after returning the item, preventing a stale phantom stack on reopening.
- A pending block edit under a resting mob now wakes its physics before the
  edited chunk is folded, so support removal is observed on that tick.

## Validation and known limitations

RC4 is not yet validated as a release. The final-tree correctness, packaged
real-client, independent breaker, matching sibling and platform gates remain
open. Industrial Spain-swarm delivery and full visual model coverage are not
proven. The million-entity research runs are not an RC4 capacity claim.
The cushion and sulfur-cube model candidates, associated entity facts and
sulfur renderer constants contain values sourced from local Minecraft bytecode;
their publication provenance remains unresolved. Do not ship them without
resolving that blocker.
